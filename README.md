# 《开锣》· 黄梅戏互动叙事

一座三百岁的老槐树，看过六十年戏，也做过一回月老——今晚，县剧团回到树下晒场，唱全本《天仙配》，而你，就是这棵树。

以第一人称"扮戏的老槐树"视角重温《天仙配》六折（思凡 · 路遇 · 上工 · 织绢 · 满工 · 槐荫别）的互动叙事作品。弘扬黄梅戏文化，让玩家在轻松的剧情选择与小游戏里，完整听懂这出"树上的鸟儿成双对"背后的故事。

## 玩法

- **剧情分支**：关键节点自由选择，仙缘 / 人情双数值沉淀出三种结局（满树繁花 · 叶落有声 · 又一出戏）
- **AI 对话**：路遇折可与七仙女、董永自由交谈（智谱 GLM 大模型实时应答，人设化回复、跑题柔性修正）；上工前可与剧团台柱云秋闲话戏班旧事
- **锣鼓节奏**：幕间一段《幕间锣鼓点》——F 键司"仓"、J 键司"台"，跟板眼敲出黄梅味
- **物件探索**：开锣前翻看蟒袍、堂鼓、戏本等八件老物件，听老树讲旧年月
- **空格键**可推进对话，选项需鼠标点选
- 谢幕有彩蛋：给老树一个词，AI 现编两句七字唱词

## 技术

纯前端单文件实现（`prototype/index.html`，无框架、无构建），打字机叙事引擎 + 双数值结局系统 + Web Audio 合成锣鼓 + 媒体时钟节奏判定 + 大模型角色扮演接入。
