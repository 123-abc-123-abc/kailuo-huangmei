## 第一部分　体验复盘报告

### 1.1 作品整体氛围与核心情绪

**一句话印象：墨色后台里的一盏暖灯。**

整体氛围是克制、内敛、带着旧物气息的温情。玩家全程处在一个"安静得能听见蝉声"的剧团后台，情绪不是靠戏剧冲突推的，而是靠物件记忆（樟脑味、缺页戏本、缠铜丝的琴筒）一层层焐出来的。核心情绪配方：

- **底色：怅惘**——六十周年、告别演出、"那时剧团四十多人"，基层剧团的黄昏感贯穿始终；

- **中段：温情**——师姐按手腕教勾脸、药罐、"有人接你"，人与人的托举是全篇最暖的部分；

- **峰值：热血**——"三声鼓。幕开了。"到开口唱那两句，是全篇唯一的炽热爆发，短促而准确；

- **余韵：释然**——三个结局都不煽情，尤其《守台》"锣响在侧幕，只有你自己听得见"，是高级的收笔。

主题句"戏比天大，人比戏大"在三条结局线上各自成立，情绪闭环完整。

**音频现状必须如实说明：MVP 尚未接入任何音频，全程静默。** 静默目前反而成全了一种"默片式文学阅读"的气质（与楷体打字机文本意外契合），但有两处硬伤：其一，晨功节奏游戏没有鼓点音效，核心玩法的反馈闭环缺失，玩家只能靠视觉判定；其二，危机与开锣两个情绪峰值缺少声音放大器。结论：音频优先级里**锣鼓点必须最先落地**（它同时是玩法反馈与叙事本体），环境音与唱段其次。

### 1.2 调色板印象

UI 层（CSS 变量）构成了当前作品的"事实调色板"：

| 角色             | 色值                                | 印象                               |
| -------------- | --------------------------------- | -------------------------------- |
| 背景 / 面板        | `#151011` / `#241a19`             | 暖黑褐，"刷了深漆的后台木构"，不是死黑             |
| 正文 / 次级 / 暗部文字 | `#f3ead8` / `#b9a98f` / `#8d7f6a` | 宣纸米白、旧纸黄、暗木色，三级文字层次              |
| 强调红            | `#b3392e`                         | 压低饱和的**朱砂红**（印章、鼓、命中线、选项圆点），不是大红 |
| 强调金            | `#c9a24b` / `#e3c27e`             | **旧铜金**（描边、数值、灯光感），不是亮金          |
| 纸面             | `#f7f1e3` / `#4a2f28`             | 选项按钮与物件卡的纸白 + 墨字                 |

五幕的色彩脚本已经在 tint 层实现了情绪-色温对位：晨青（练功）→ 暖黄（后台）→ 琥珀（侧台）→ 金褐（妆镜）→ 红金（舞台）。这条色温曲线本身就是设计资产，后续所有插图配色必须服从它。

**总体印象：这是一套"暗色戏台 + 纸墨 + 朱金点睛"的传统后台色系，克制、有做旧质感、与题材高度互文。红与金的使用面积被严格限制在小元素上，大面积让给墨与纸——这个纪律是作品目前审美上最成熟的部分，插图绝不能破坏它。**

### 1.3 剧情节奏

**定性：治愈为底、热血为爆点、怅惘为余韵的"静水深流型"节奏。** 不压抑、不致郁、不轻松；悬疑只在中段闪现一次（药罐伏笔 → 失声危机），用得克制。

节奏曲线：文学慢热（序幕 + 晨功）→ 物件沉浸（第二幕）→ 情感铺垫（第三幕）→ 骤变（第四幕）→ 仪式缓冲（第五幕 A 线勒头小游戏，妙笔：高潮前刻意降速）→ 释放（第六幕）→ 余韵（结局 + 彩蛋）。

亮点：

- 第四幕的短句排比（"六百张票。省城来的专家评审。建团六十周年。"）是全篇节奏最好的段落，三行三个重锤；

- 勒头小游戏放在危机与开锣之间，形成"吸气-屏住-呼出"的呼吸结构；

- 三结局情绪梯度分明：《满宫满调》热血圆满、《接唱》温情遗憾（个人认为回味最长）、《守台》内敛余韵。

隐患：

- 第二幕 8 条物件文本每条 3 行，连续阅读到第 5-6 条有疲劳点，物件配图（特写图 + 短文本）是体验最大增量；

- 晨功节奏游戏无声，玩法紧张感上不来；

- 结局屏全部为纯文字，三个情绪落点都没有视觉记忆锚（e1 预留的视频槽位还是 null）。

### 1.4 角色与场景的直观视觉印象

- **小满素装立绘**：工笔线条质量高（发丝、盘扣、衣纹），气质温婉沉静，与"功夫扎实但怯场"人设相容；大面积月白素色建立了"将满未满"的角色隐喻，高级。但右下角朱印被画幅裁切一半，是硬伤。

- **小满三视图**：合格的工程锚点，发型一致性达成；但画风实际偏"新国风动画设定稿"（偏大的眼睛、平涂），与宣称的"水墨淡彩"有距离。

- **练功房场景**：五场景中水准最高的一张。水彩绘本感、约六成留白、灯笼暖光与晨雾青光的冷暖对峙成立，三角构图稳健，"计白当黑"的留白是给 HUD 和对话框让的位，方向完全正确。

- **占位状态**：韩师傅 / 云秋 / 陈团长目前都是金色竖排文字占位框——文字本身有戏台味，但情感浓度远跟不上文本。第二幕物件是纯文字图标（袍 / 镜 / 琴），雅但信息量低。

- **总体**：文本完成度约九成，视觉供给约一成半——"一桌好菜只有一道上了盘"。

### 1.5 当前 MVP 插图资源的观感短板（按严重度排序）

1. **视觉覆盖率过低（最致命）**：5 个场景仅 1 张、7 个角色仅 1 张、8 个物件 0 张、剧情 CG 0 张、海报 0 张。四分之三的游戏时长里，玩家看到的是纯渐变底色 + 文字，空间感断裂。
2. **风格漂移风险**：人物（三视图 / 立绘）偏新国风动画（大眼、平涂、细描边），场景偏水彩绘本（无轮廓线、湿染）。两者同屏（立绘槽叠在场景图上）会出现"动画人物贴在水彩画上"的拼贴感。需要在方案层面统一（见第二部分）。
3. **明度冲突**：练功房是高明度宣纸调（墙面约占画面一半、明度约 85%），UI 是深色系。接入后亮背景会吃掉 HUD 金色文字与竖排场景标签的可读性。新场景生成必须控制整体明度并让画面顶部略沉。
4. **立绘非透明 + 槽位比例错配**：立绘带米白纸底，在深色场景上会呈"纸片浮起"效果；且游戏立绘槽为 150×340 的全身竖槽，现有半身立绘用 contain 缩放后上下大量留空。白衣与米白底同色，后期抠图会把衣服一起抠掉。
5. **印章问题**：立绘右下角朱印被裁切一半（构图硬伤），且与标题屏"开演"印章的 UI 语义撞车。AI 随机印章内容不可辨虽在双盲安全线内，但观感不专业。
6. **结局与高潮无图**：第六幕"台下的灯像一片倒过来的星海"是全篇最有画面感的一句，目前只有文字。三结局同理。
7. **无主视觉海报**：提交材料、报告封面、展示视频都没有一张能代表作品的门面图。

## 第二部分　专业美术资源分析与方案

### 2.1 画风分类

**结论：水墨淡彩·新工笔绘本风（工笔线描 + 水彩渲染的混合技法），按资源类型分级执行。**

| 资源类型  | 技法定位                   | 说明              |
| ----- | ---------------------- | --------------- |
| 角色立绘  | 工笔线描骨架 + 淡彩平涂 + 局部柔渐变  | 细墨线勾边，设色不超过三成饱和 |
| 场景背景  | 水彩湿染 + 大留白 + 无轮廓线      | 物体边缘靠水迹晕开，不勾线   |
| 剧情 CG | 工笔人物（有线）+ 水彩背景（无线）七三混合 | 高潮 CG 加重墨与饱和度   |
| 物件特写  | 工笔小品（宋人册页感）            | 磨损质感是叙事信息，必须画足  |
| 海报    | 上述全要素的集大成              | 允许这一张最"满"       |

候选风格排除理由：二次元厚涂（受众与气质错位，丢戏曲的雅）；扁平矢量（无笔墨质感，商业感过强）；像素风（情绪完全错位）；写实渲染（人脸一致性重灾区，已决策排除）；低多边形（错误）；复古胶片插画（仅适用于"1985 老照片"单一物件）；纯赛璐璐（硬高光与大眼会拉向日系动画，破坏水墨身份）。

**关键纠偏**：现有锚点的大眼倾向不必回炉（一致性链已建立、成本不可逆），但**新生成角色（云秋 / 陈团长 / 韩师傅 / 老魏）应在提示词中显式压低眼睛尺寸与高光强度**，向工笔"细目"靠拢半档，让人物群像整体往水墨侧回归。这是成本最低的风格收敛手段。

### 2.2 光影方案

| 场景        | 光影                  | 理由               |
| --------- | ------------------- | ---------------- |
| 场景背景 / 物件 | 软漫光（阴天漫射），无硬投影      | 水彩体质靠明度差塑形，不靠影子  |
| 角色立绘      | 柔和顶前光（舞台顶光的弱化版），低对比 | 立绘要通用，不能带强方向光    |
| 危机 CG     | 冷侧光（窗光从侧后打入），冷暖对峙   | 紧张感来自色温撕裂，不来自暗黑  |
| 勒头 CG     | 暖黄单灯顶光，小范围聚光        | 妆镜灯的仪式感          |
| 开锣 CG     | 舞台追光锥形光束 + 台下反光     | 全篇唯一允许"戏剧化打光"的一张 |

全局禁止：写实硬阴影、多光源混战、镜头光晕、景深光斑。阴影色调统一为**暖黑褐**（#1a1310 系），禁止冷灰黑。

### 2.3 色彩方案

| 项         | 定义                                                         |
| --------- | ---------------------------------------------------------- |
| 主色（约 70%） | 墨黑 `#1f1a17`、宣纸白 `#f7f1e3`——画面骨架                           |
| 辅色（约 20%） | 暖木褐 `#6b4a35`、黛青 `#46565a`、苍绿 `#7a8a76`                    |
| 强调色（<10%） | 朱砂 `#b3392e`、鎏金 `#c9a24b`——只给印章、幕布、鼓、灯光、头面                 |
| 饱和度       | 全局 30-50% 中低饱和；仅开锣 CG 允许强调色到 60-70%；禁荧光                    |
| 色温        | **暖调为体，冷调为用**：序幕晨青冷 → 后台暖黄 → 侧台琥珀 → 危机冷灰 → 开锣炽暖红金 → 谢幕回归墨色 |

连续性铁律：五张场景必须是"同一张宣纸上画出来的组画"——统一旧纸底色、统一做旧质感，杜绝每张各调各的。

### 2.4 构图类型

- **场景背景**：三分法 + 对角呼应 + 约 60% 留白（给 HUD 与对话框让位）；画面顶部略沉保证 HUD 可读。

- **角色立绘**：中轴构图，膝上截半身或全身，纯色底。

- **剧情 CG**：单人关键时刻用中心构图；双人（教勾脸、接唱）用三分对视；开锣用宽银幕横幅构图。

- **海报**：竖版中轴对称（戏台的对称美学），上三分之一留白给标题，右下留白给印章排版。

### 2.5 画布比例

| 资源    | 比例                 | 备注                 |
| ----- | ------------------ | ------------------ |
| 场景背景  | 16:9（1920×1080 起）  | 游戏背景，cover 满铺      |
| 角色立绘  | 3:4 竖版             | 透明 PNG 或纯纸底        |
| 剧情 CG | 16:9；开锣 CG 可选 21:9 | 开锣 CG 兼作图生视频关键帧    |
| 主视觉海报 | 3:4（移动端展示可另出 9:16） | 提交材料 / 报告封面 / 视频封面 |
| 物件特写  | 1:1                | （不在本批，沿用本方案体系）     |

### 2.6 细节程度

- 场景：**中等**。远景虚、中近景实，宁空勿满——场景是舞台，不是主角。

- 立绘：面部 / 手部**高精**，服装中精，无背景。手是本风格最高频崩坏点，提示词必须显式约束。

- 剧情 CG：开锣**高精**（全篇门面），其余中高。

- 原则：细节密度与叙事重要性正相关，不为细节而细节。

### 2.7 线条处理

- 人物 / 物件：**细墨线勾边**（工笔铁线描的轻量版），线色用淡墨褐而非纯黑，粗细均匀。

- 场景：**无轮廓线**，靠水彩边缘晕染。

- CG：人物有线、背景无线——用线的有无区分"戏里人"与"戏外景"，恰好暗合主题。

- 禁止：粗黑描边（漫画感）、完全无线的厚涂（丢工笔身份）。

### 2.8 雷点与负面提示词清单（四组）

**A. 风格污染**：写实照片、3D 渲染、西方油画、厚涂笔触、赛璐璐硬高光、日系动漫大眼（新角色）、韩漫风、Q 版萌化。

**B. 题材污染**：京剧脸谱、京剧大头面、厚重凤冠、靠旗（本作是黄梅戏，扮相应简洁古装化）、和服韩服、西方天使翅膀、赛博朋克元素、现代物品（空调 / 电线 / 塑料 / 不锈钢 / 运动鞋 / 现代建筑）。

**C. 技术瑕疵**：文字、水印、签名、**印章**（AI 随机印章一律不要，印章由后期 UI 统一排版）、乱码假字、多余手指、畸形手部、肢体错乱、双人交缠错误、比例失调、多余肢体。

**D. 构图光效**：镜头光晕、景深虚化光斑、鱼眼强透视、高饱和荧光色、暗黑哥特、恐怖血腥元素。

**两个特殊雷点**：

1. 手抄戏本特写：AI 画"毛笔小楷"几乎必出乱码假字。提示词要求"字迹工整但模糊不可辨认"，或生成后后期贴真实文字。
2. 老照片物件：生成后必须加做旧褪色滤镜；避免生成清晰可辨的真实人脸（版权 + 恐怖谷双雷）。

### 2.9 立绘呈现的技术路线（解决短板 4 与 5）

- **快路径（推荐，零抠图风险）**：接受纸底，把立绘槽做成"册页 / 挂轴"样式——立绘外加一圈细金边内衬，像挂在后台的一幅戏装画像，融入"后台物件"世界观；同时把立绘槽比例从 150×340 调整为与半身像匹配的 3:4。

- **精路径**：新生成立绘时底色改为淡青灰（与月白衣服拉开明度差），后期抠图为透明 PNG。逐张验证衣服边缘完整。

- 印章：现有立绘的裁切朱印，若走册页路线可用细金边框自然遮蔽；重生成版本一律在负向词中排除印章。

## 第三部分　AI 绘图提示词批次（可直接投产）

> 使用规则：
>
> 1. **统一风格后缀**（升级 02 版，替换旧后缀）：`中国水墨戏曲风格插画，工笔线条勾勒人物，水墨淡彩设色，宣纸质感，柔和软漫光，中低饱和度，暖调旧纸色，留白构图，高质量细节，画面中无任何文字、无水印、无印章、无签名`
> 2. **统一负向后缀**：`写实照片，3D渲染，西方油画，厚涂笔触，赛璐璐硬高光，日系动漫大眼，现代服装，现代物品，京剧脸谱，京剧大头面，厚重凤冠，靠旗，文字，水印，印章，签名，乱码，多余手指，畸形手部，肢体错乱，高饱和荧光色，镜头光晕，暗黑恐怖`
